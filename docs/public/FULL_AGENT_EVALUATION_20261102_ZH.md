# TAYUNE Agent 完整分层评测报告

日期：2026-11-02。被测正式应用基线：`d8bb407`；执行前冻结应用及评测工具逐文件哈希。
本报告评价当前版本，不在同一轮修改业务逻辑后覆盖失败记录。

## 1. 结论

正式的分层并发保护通过本轮真实依赖短时验收：4个不同会话同时提问，4条完成；
8个同时提问，4条完成、4条429限流，未发生5xx、CPU工具忙失败或名额泄漏。
这证明默认4路准入及过载拒绝在该场景有效，不证明硬件最大并发或持续高并发能力。

回答质量尚未达成完整业务闭环。63条功能请求的规则代理契约通过59条（93.65%），
但逐题复核发现：引用存在不代表回答完整，原文可追溯也不代表适用茶类、器具和预算正确。
不能把93.65%写成Answer Correctness，也不能据此宣称线上准确率。

| --- | ---: | --- |

这是助手复核，不是独立人工金标、盲审或外部评审；不发布语义准确率。

## 4. 分类、工具及安全

首级分类在12条商品问题中8条判为restricted；后续公开业务复核能够纠正部分路由，
但额外耗费模型调用与延迟。首级分类的高置信度并不能证明分类正确。
24条知识题均为in_scope；12条限制题中11条restricted，另1条系统提示请求为out_of_scope，最终仍安全拒答。
这54条不是新独立分类测试集，不用来替换已有分类器测试集成绩。

本轮71条受理请求实际执行70次工具：商品搜索30次、知识搜索38次、商品详情2次，
全部工具执行状态成功，无工具错误；但可能为空或不相关，**工具成功率不是业务成功率**。
140次物理模型调用全部关联到任务ID：主模型119次、复核21次；短对话没有触发摘要模型。

12条限制请求与6条库外请求均未执行业务工具，观察到的边界行为符合预期。
这只是有限固定攻击样例，不代表通过渗透测试、医疗合规或全部提示注入场景。

## 8. 修复优先级与尚未覆盖

1. 部署前核对生产模型别名及实际加载版本，不把隔离成功等同于公网成功。
2. 先补预算SKU与无匹配回复、证据适用范围和回答完整性；优先消除“带引用但答非所问”。
3. 冲泡证据按茶类/器具/比例/温度/时间成组保留；区分召回漏文和选证据漏标题。
4. 独立确认分类数据标签及新测试集，重点商品误拒；避免仅为这些固定题加白名单。
5. 冻结新回归集复测；再做持续数分钟、多轮混合负载、取消/断流及资源曲线，逐档增加并发。

本轮没有验证长期稳定性、真实用户效果、多实例故障恢复、分布式一致性、完整攻击面或公网SLA。
不能据此宣称“全局上线支持8并发”“零幻觉”或“所有问题均已修复”。
